# Спайк SwiftTerm

Окно SwiftUI с вкладками на [SwiftTerm](https://github.com/migueldeicaza/SwiftTerm). В каждой вкладке
`agentmeister <проект> -n -x` запускает агента так же, как во вкладке iTerm2, вместе с mihomo и sandbox-exec.
Задача спайка в том, чтобы понять, выдержит ли SwiftTerm Claude Code и Codex в ежедневной работе, прежде чем
строить на нем приложение.

## Запуск

Собирать и запускать из обычного терминала. В proxy-сессии SwiftPM падает с
`sandbox_apply: Operation not permitted`, у него своя песочница macOS.

```sh
cd ~/Developer/agentmeister/app
swift run AgentmeisterSpike                  # agentmeister через proxy
swift run AgentmeisterSpike kcalm            # другой проект
swift run AgentmeisterSpike --direct         # напрямую
swift run AgentmeisterSpike --codex          # Codex
swift run AgentmeisterSpike --menu           # главное меню agentmeister, в нем иконки OSC 1337
swift run AgentmeisterSpike -- --resume      # аргументы после -- уходят агенту
```

⌘T открывает еще одну вкладку с тем же запуском, ⌘W закрывает, ⌘1…⌘9 переключают, ⌘⇧R запускает заново
вкладку, где процесс завершился.

Вкладка получает `TERM=xterm-256color`, `COLORTERM=truecolor` и `TERM_PROGRAM=Agentmeister`. Переменные proxy,
iTerm2 и Claude Code из окружения, откуда запустили спайк, убираются.

`FORCE_HYPERLINK=1` нужен для ссылок в строке promptsill. Claude Code решает, оставлять ли OSC 8, по списку
известных терминалов, и Agentmeister в нем нет.

`MNRH_ICONS=emoji` выключает картинки OSC 1337 в меню agentmeister. SwiftTerm 1.99.3 стирает все картинки
строки, как только в нее пишется любой текст (`clearTextOverwrittenImagesFromLine`), а меню пишет название
пункта сразу после иконки. iTerm2 стирает только клетки под новым текстом. В приложении меню заменит
нативный интерфейс, поэтому чинить это в SwiftTerm пока не нужно.

## Результаты, 24 ноября

Меню, ввод, Shift+Enter, вставка текста и картинок, прокрутка длинного вывода, изменение размера окна,
несколько вкладок и Codex работают. На выводе большого файла спайк брал 17.7% CPU и 0.8% GPU, в простое 0%.
Иконки меню и ссылки promptsill сначала не работали. После исправлений выше emoji в меню видны, ⌘-клик
по ссылкам в строке promptsill открывает браузер. SwiftTerm подходит как основа приложения, осталась
неделя обычной работы в спайке.

## Что проверить

Отметь, что работает, и запиши, что нет.

- [x] Меню agentmeister рисуется, стрелки и Enter работают, иконки видны (пока emoji, см. ниже).
- [x] Claude Code открывается, ввод не теряет символы, кириллица и emoji не ломают ширину строк.
- [x] Shift+Enter переносит строку, вставка длинного текста и картинки (Ctrl+V) доходит до агента.
- [x] Длинный ответ и вывод сборки прокручиваются без рывков, процессор не уходит в 100%.
- [x] Строка promptsill цветная, ⌘-клик по "прокси KZ" и ветке открывает ссылку.
- [x] Заголовок вкладки меняется вместе с заголовком, который ставит агент.
- [x] Изменение размера окна не ломает экран Claude Code.
- [x] Codex (`--codex`) рисуется так же хорошо.
- [ ] Неделя работы в спайке без желания вернуться в iTerm2.

## Чего в спайке нет

`/restart` не сможет найти вкладку, он знает только Terminal и iTerm2. Уведомления по клику не переводят во
вкладку спайка. Нет боковой панели, настроек, стекла и тем. Все это задачи приложения, если спайк пройдет.
